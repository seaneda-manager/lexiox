## 1. 한눈에 보기

**LEXiOX는 영어 학원 운영과 학생 학습을 하나로 묶은 시스템입니다.**

학생은 *"배운 것을 잊지 않게"* 공부하고, 선생님은 *"오늘 무엇을 해야 하는지"* 한눈에 알고, 원장은 *"학원이 잘 돌아가는지"* 숫자로 확인하고, 본사는 *"가맹점 전체의 상태"* 를 봅니다.

### 핵심 세 가지
1. **잊어버리기 전에 다시 보게 하는 학습** — 학습 중 모르거나 틀린 단어는 자동으로 복습 대상이 되고, 정해진 날짜에 복습·총 시험으로 이어집니다. 선생님이 따로 챙기지 않아도 됩니다.
2. **"오늘 할 일" 한 화면** — 출석 미체크, 복습이 밀린 학생, 새 숙제 제출을 **급한 순서**로 보여줍니다.
3. **역할마다 다른 화면, 직급마다 다른 권한** — 원장·선생님·본사가 각자 필요한 것만 봅니다. 선생님 직급별 권한은 원장이 정합니다. 🔜 (권한 저장·가맹점 구분은 준비 중)

## 2. 누가 무엇을 하나

| | 본사 | 원장 | 선생님 | 학생 |
|---|---|---|---|---|
| 하는 일 | 콘텐츠 제작·배포, 가맹점 관리 | 학원 운영, 선생님·학생·반 관리 | 수업, 출석, 배정, 학생 지도 | 공부, 숙제, 시험 |
| 처음 보는 화면 | **본사 허브** ✅ | **오늘 현황** ✅ | **오늘 할 일** ✅ | 학습 홈 ✅ |
| 핵심 질문 | 가맹점이 잘 쓰고 있나? | 오늘 처리할 일이 뭐지? | 내 수업·학생은 어떤가? | 오늘 뭘 공부하지? |

### 2.1 본사
- **본사 허브** ✅: 이번 주 학습한 학생 수, 가맹점 현황 표(가맹점·학생·이번 주 학습·출석 미체크·복습 밀림·상태), 지표 요약, 콘텐츠 현황(단어·Reading·Listening·내신 지문 개수).
- **콘텐츠 제작·관리** ✅: TOEFL(Reading·Listening·Speaking·Writing), 단어, 문법, 내신(고등·중학), Jr. 콘텐츠를 본사가 만들고 가맹점이 함께 씁니다.
- **공지 · 가맹점 문의 · 교육 · 자료실** 🔜: 가맹점과 소통하는 도구입니다. 지금은 안내 화면만 있고, 가맹점 구조와 함께 차례로 열립니다.
- **가맹점별 비교** 🔜: 가맹점이 추가되면 허브 표에 한 줄씩 늘어납니다.

### 2.2 원장
- **오늘 현황** ✅ — 한 화면에서 이것을 봅니다.
  - **오늘 확인할 일 N가지** (가장 급한 것부터 목록)
  - 출석 체크가 안 된 수업, 복습이 2일 이상 밀린 학생, 오답 검토 대기, 총 시험 시기가 된 학생
  - 오늘 수업 수, 오늘 출석률, 수업별 출석 체크 진행 상황
- **학생·반 관리** ✅: 학생 추가·수정, 반과 시간표, 학부모 연락처, 학교 관리.
- **선생님이 하는 일 모두** ✅: 원장은 선생님 화면을 전부 볼 수 있습니다.
- **선생님 직급·권한 관리** 🔜: 원장이 직급(예: 부원장·정교사·조교)을 만들고, 직급마다 할 수 있는 일을 정합니다.
- **본사 소식(공지·교육·자료)** 🔜

### 2.3 선생님
- **오늘 할 일** ✅: 내 오늘 수업, 출석 체크 진행, 새 숙제 제출, 복습 밀린 학생.
- **오늘의 수업** ✅ → 수업을 눌러 출석 체크.
- **학생 현황** ✅, **단어 복습 현황** ✅, **활동 리포트** ✅.
- **배정** ✅: 숙제·단어·시험 배정, 배정 캘린더, 단어 시험 출제(범위·문항 수 선택).
- **수업 로그** ✅
- 학생 추가, 학부모 연락처, 반 관리 같은 **원장 업무는 보이지 않습니다.** (직급에 따라 달라질 수 있음 🔜)

### 2.4 학생
- 학습 홈에서 오늘 할 것을 확인하고, 교재별로 단어 학습 → 복습 → 시험을 이어갑니다.
- TOEFL, 내신, Jr. 등 **배정된 프로그램의 메뉴만** 보입니다.

## 3. 학생은 어떻게 공부하나 — 단어 학습 흐름 ✅

한 번의 학습(1 Day)은 아래 순서입니다. **한 화면에 모든 버튼이 보이고**, 큰 글씨로 편하게 풀 수 있게 만들었습니다.

| 순서 | 단계 | 하는 일 |
|:-:|---|---|
| 1 | 어휘 확인 | 단어를 보고 "알아요 / 아직 몰라요" 선택 |
| 2 | 철자 확인 | 아는 단어는 뜻을 보고 철자를 직접 입력 |
| 3 | 단어 학습 | 철자와 뜻을 입력하며 익히기 (맞으면 자동으로 넘어감) |
| 4 | Speed Check | 제한 시간 안에 단어 맞히기 |
| 5 | **깜지** | 철자 **+ 뜻**을 3번 쓰기. 1회차는 정답을 보여주고, 2회차는 첫 글자만, 3회차는 아무것도 안 보여줍니다 |

### 3.1 자동 복습 ✅ — "다시 보지 않으면 잊는다"
- 학습 중 **모른다고 한 단어**와 **Speed에서 틀린 단어**는 **자동으로 복습 대상**이 됩니다.
- **복습 1회차**(다음 날)와 **2회차**(그다음 날)는 필수입니다.
- 1·2회차에서 틀린 단어만 **3회차**에 한 번 더 나옵니다. 다 맞히면 졸업입니다.
- 하루를 빼먹어도 괜찮습니다. 밀린 복습은 사라지지 않고 이어서 나옵니다.
- 선생님은 **복습 현황** 화면에서 학생별로 *오늘 복습할 개수 · 며칠째 밀렸는지 · 마지막 복습일*을 한눈에 봅니다.

### 3.2 시험 ✅
| 시험 | 설명 |
|---|---|
| Day 시험 | 방금 학습한 Day에서 **약했던 단어 위주**로 출제 (전부 출제하지 않아 부담이 적음). 출제 단어 수는 원장·선생님이 설정 가능 |
| 복습 시험 | 오늘 복습할 단어로 출제 |
| **총 시험** | 기본 **30일마다** 열리는 누적 시험. 그동안 배운 단어 중 약한 단어를 먼저 출제. 간격은 학생·반·전체 단위로 설정 (2주마다 등으로 변경 가능) |
| 선생님 단어 시험 | 선생님이 **교재·Day 범위·문항 수·유형**을 정해 학생에게 배정하는 시험 |

시험은 단어→뜻, 뜻→단어, 동의어, 듣기 문제로 구성되며, 점수·연속 정답(콤보)·힌트가 있습니다.

### 3.3 교재가 여러 개여도 ✅
학생에게 교재(예: 해커스 토플 보카, 올림포스 영어독해)를 여러 개 배정해도 **교재별로 따로** 학습·시험·복습이 관리됩니다.

## 5. 출석과 반 운영 ✅

- 반(수업 시간대)을 만들고, 담당 교사·주간 시간표·학생을 배정합니다.
- 시간표를 등록하면 **앞으로 2주치 수업이 자동 생성**됩니다.
- 선생님은 수업을 열어 출석·지각·결석·사유결석을 체크합니다.
- 원장은 하루 전체 **출석 현황**(반별 체크 여부, 지각·결석 학생 목록)을 봅니다.
- 오늘 출석 체크가 안 된 수업은 **원장·선생님 홈에 가장 위에 경고**로 나옵니다.

## 6. 선생님 직급과 권한 🔜

> 이 기능은 **준비 중**입니다. 아래는 계획된 동작입니다.

- 원장이 가맹점마다 **직급**을 만듭니다. 기본으로 *부원장 · 정교사 · 조교* 3개가 제공되고, 이름과 권한을 자유롭게 바꿀 수 있습니다.
- 직급마다 허용할 기능을 체크합니다.

| 권한 | 쉬운 설명 |
|---|---|
| 오늘의 수업 / 출석 | 내 수업 보기, 출석 체크 |
| 숙제 관리 / 배정 / 시험 출제 | 숙제·단어·시험 배정과 출제 |
| 학생 현황 / 리포트 | 학생 상태와 학습 리포트 보기 |
| 학생 추가·수정 | 신규 학생 등록 |
| 학부모 연락처 | 학부모 정보 보기 (민감 정보) |
| 반·시간표 관리 | 반 만들기와 시간표 |

- 원장은 자신이 가진 권한 **안에서만** 선생님에게 권한을 줄 수 있습니다.
- 누가 언제 권한을 바꿨는지 **기록**이 남습니다.

**데모에서는:** 본사(Super) 계정에서 화면 위쪽의 **역할 전환 버튼(Super / 본사직원 / 원장 / 선생님)** 으로 각 역할이 보는 화면을 바로 보여줄 수 있습니다. ✅ *(이 전환은 화면 구성만 바꾸고 실제 권한은 바뀌지 않습니다.)*

## 8. 자주 묻는 질문 (영업용)

**Q. 선생님이 바뀌어도 학생 기록이 남나요?**
A. 학습 기록은 **학생에게** 남습니다. 선생님이 바뀌어도 이어집니다. ✅

**Q. 다른 학원(가맹점) 선생님이 우리 학생 정보를 볼 수 있나요?**
A. 가맹점별 데이터 분리는 **준비 중**입니다. 🔜 오픈 전에 가맹점 간 정보가 보이지 않는 것을 시험으로 확인한 뒤 제공합니다. (영업 시 일정을 안내하기 전에 확인 필요 ❓)

**Q. 선생님마다 볼 수 있는 정보를 다르게 할 수 있나요?**
A. 직급별 권한을 원장이 정하는 기능이 **준비 중**입니다. 🔜 지금도 원장과 선생님 화면은 다르게 구성됩니다. ✅

**Q. 학생이 복습을 안 하면 어떻게 되나요?**
A. 복습은 사라지지 않고 이어서 나옵니다. 선생님·원장 화면에 **복습이 밀린 학생**이 표시되어 챙길 수 있습니다. 복습을 하기 전에는 새 학습을 막는 기능은 필요에 따라 추후 도입할 수 있습니다. ✅

**Q. 교재는 어떤 것을 쓸 수 있나요?**
A. 본사 콘텐츠(2026-11-05 기준 단어 약 7,400개, 단어책 380여 Day, Reading 7·Listening 10 세트, Hi-내신 지문 270여 개 등)를 공통으로 씁니다. 가맹점 자체 교재 제작은 현재 제공하지 않습니다. 새 교재는 본사가 추가합니다. ❓ *(수치는 영업 직전에 갱신)*

**Q. 학부모에게 리포트를 보낼 수 있나요?**
A. ❓ 확인 필요 (운영 상태 확인 후 안내)

**Q. 컴퓨터 없이 태블릿·휴대폰으로도 되나요?**
A. 웹 기반이라 브라우저로 사용합니다. 화면은 한 화면에 맞게 설계했습니다. ❓ *(모바일 화면 점검 후 안내)*

- [ ] **기능 상태(✅/🔜/❓) 최신화** — 특히 ❓ 항목(학습 게임, 학부모 소통, 모바일)
- [ ] **수치 갱신** — 콘텐츠 개수는 "본사 허브 > 콘텐츠 현황"에서 확인해 날짜와 함께 기재
- [ ] **가맹점 구분·직급 권한 출시 일정** — 영업에서 약속하기 전에 개발 일정 확인 (설계서 2-A ~ 2-D)
