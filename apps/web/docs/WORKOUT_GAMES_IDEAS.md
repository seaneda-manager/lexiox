### 드리프트 개편 (2026-11-15)
- **콕핏뷰(의사 3D)** 모드 추가: 탑뷰와 같은 트랙·물리·점수를 쓰고 화면만 차 안 1인칭 원근 도로로 그린다(절반 해상도 캔버스를 확대, 핸들·계기판·룸미러 오버레이). 폰 성능은 큰 걱정 없다는 판단.
- **콕핏뷰 시인성 수정(2026-11-15, 사용자 피드백 "도로가 잘 안 보이고 막 그러네")**: ① 카메라 방향을 차 방향과 속도 방향의 중간으로 부드럽게 따라가게(드리프트해도 화면이 확 돌아가지 않음) ② 카메라 높이 40→58, 아스팔트 밝게·들판 어둡게·연석 넓게·중앙선 굵게 ③ 그림 오류 2개 수정: 들판 띠가 도로 조각을 덮어 생기던 톱니 줄무늬(2패스로 분리), 카메라에 너무 가까운 연석 점이 하늘을 가로지르는 빨간 띠로 투영되던 문제 ④ 코스를 벗어나면 "OFF TRACK" + 트랙 방향 화살표, 1.2초 넘게 벗어나면 "트랙으로 복귀(R) +3초" 버튼(탑뷰에도 적용). 잔여: 급한 코너 바로 앞에서 가까운 도로 조각이 비는 현상이 약간 있음.
- **후진(2026-11-15, "차 뒤로가기")**: ↓/S(폰은 BACK 버튼) — 달리는 중에는 브레이크, 거의 멈추면 후진(최고 260px/s, HUD에 "R" 표시). 후진 중 GAS를 누르면 빨리 멈추고 전진. 후진 중 핸들은 실제 차처럼 반대로 도는 것(우회전 입력 → 차체 방향이 반시계). 탑뷰·콕핏뷰 공통.
- **어시스트 모드**: 드리프트가 낮은 조건에서도 걸리고, 스핀 보정이 강하고, 잠깐 코스를 벗어나도 체인을 봐준다. 대신 드리프트 점수 ×0.7, 최고 기록은 별도 저장.
- **게이트 점수 차등**: 그냥 통과 300 / 드리프트로 통과 600 + 미끄러진 각도에 따라 최대 +300(= 최대 900), 각도 0.6rad 이상이면 "PERFECT DRIFT GATE".

## 2. 아이디어 백로그 (미착수)

### Word 오목 (2026-11-15, 구현됨·AI 대전) — 규칙 확정판
`OmokGame.tsx`, 11x11. **정식 오목 + 철자 획득 점수제.**
- 차례는 번갈아, 돌은 항상 놓인다. 매 수마다 문제는 뜨지 않는다.
- 공격을 만들면 자기 목표 단어의 철자를 1글자 얻는다(다음 글자를 4지선다로 고르기, 10초): **열린 3목 / 막힌 4목 / 열린 4목** (같은 줄·같은 종류는 한 번만, 막힌 3목은 해당 없음. 열린 3목은 "열린 4목으로 키울 수 있는" 진짜 열린 3목만).
- 철자 +100, 단어 완성 +300(다음 단어로 교체). 목표 단어는 사람/AI 각자 따로(길이 3~10글자 가변).
- **5목을 먼저 만들면 즉시 승리**(점수 무관). 각자 20수까지 5목이 없으면 점수 높은 쪽 승리.
- AI는 철자 문제를 난이도별 확률(50/72/90%)로 맞힌다. AI 수는 휴리스틱(공격+수비), 난이도로 상위 후보 폭이 다름.
- 단어 길이를 승리 줄 길이에 묶으면 짧은 단어(3~4목)에서 열린 3목만으로 승부가 나 균형이 깨지므로 폐기. 5목 고정.
- 검증: 열린3/막힌3/벽 옆3/열린4/막힌4/5·6목/대각선/3-3 동시/중복 방지 로직 확인. 점수 카드·철자 문제 창 화면과 실제 한 판은 미확인. 2인 대전은 다음 단계.

### WORD SPORTS (2026-11-15, 1단계 구현) — 올림픽 계열 허브
이름은 임시(올림픽 명칭은 IOC 상표 이슈). 카탈로그 그룹 `sports`에 종목을 모드로 추가하는 구조.
- **클레이 사격** `ClayGame.tsx` (960x540): 좌우 트랩에서 단어 붙은 접시가 날아오른다. 마우스/터치 조준·클릭 발사, 장전 2발(소진 시 0.9초 재장전). 정답 접시 +100(+콤보), 오답 접시 -50, 정답 접시를 놓치면 목숨 -1(3개). 라운드 10개. 판정 로직 확인(정답/오답/빗나감).
- **100m 달리기** `SprintGame.tsx` (960x540): 1~4키/터치로 정답을 고를수록 가속(빨리 맞히면 더), 오답은 비틀거림+0.65초 입력 정지. 정답이 없어도 조깅 속도(4.2m/s)는 유지. 상대 3명(난이도: 쉬움/보통/어려움 = 평균 5.9/7.0/8.2m/s). 보통 기준 시뮬레이션: 정답 1~2초에 한 번 → 10~13초(승), 3초에 한 번 → 약 19.6초(패), 무응답 → 23.8초. 
- **영영 문제 배려(2026-11-15)**: 정의 문장은 읽는 데 시간이 걸려 즉각 반응이 어렵다는 피드백 → 문제 길이(단어 수)에 비례한 "읽는 시간"(1.2~4.2초) 동안 감속을 30%로 줄이고, 빠른 정답 보너스 창도 읽는 시간+1.8초로 늘림. 오답 패널티 완화(속도 ×0.62, 정지 0.5초, 비틀 0.55초). 시뮬레이션(보통 상대 약 15.5초): 문제가 뜬 뒤 3초에 답 → 13.1초, 4초 → 16.4초(이전 21.1초), 5초 → 18.7초, 6초 → 19.9초.
- 남은 종목: 계주, 크로스컨트리, 역도, 야구, 스노보드, 컬링, 당구.
- 미확인: 두 게임 모두 화면에 렌더된 모습과 실제 조작은 못 봄(브라우저 창이 숨겨져 프레임이 안 돎).

### WORD RESCUE (2026-11-15, 1차 구현) `RescueGame.tsx`
- 횡스크롤 헬기(960x540, 세계 폭 3400). 위에 뜻, 지상의 인원들은 철자 태그. **글자를 정해진 순서대로** 태워 기지에서 내려놓으면 단어 완성(3단어 = 1회).
- 착륙(저속·바닥 접촉)하면 근처의 "다음 글자" 인원이 달려와 탑승(좌석 4). 순서가 아닌 글자는 타지 않음(흔들림). 기지 패드에 착륙하면 순서대로 하차(+100/글자, 단어 완성 +300, 장갑 +1).
- 위협: SAM 3기(유도 미사일, 헬기를 추적), 대공포 4기(예측 사격, **공중에 있을 때만** 발사 → 착륙은 대공포에서 안전). 피격 시 장갑 -1(3개), 탑승 중이던 인원은 떨어져 지상에 다시 나타남.
- 무기: 기관총(Space, 눌러서 연사, 지상 쪽으로 약간 아래), 로켓(Shift/X/B, 최대 5발, 범위 피해). 미사일 +25, SAM +200, 대공포 +150.
- 폰: 조이패드 + FIRE/ROCKET 버튼. 검증: 7글자 단어 전체 구출·하차·완성(1000점), 미사일 발사/유도/피격/격추, SAM 파괴, 대공포(공중만 발사). 화면 렌더와 실제 조작은 미확인.
- **보기 = 적기, 단어는 붙이지 않음**(사용자 확인 2회): 적기는 단어 없이 날아와 사격하는 적 전투기. 기관총/로켓으로 격추 가능(+50). 목표 단어는 공개하지 않고 글자 수만 `_ _ _`로 보인다.
- **철자 규칙**: 지상 인원은 아무 글자나 태울 수 있지만(바로 옆에 내려앉은 인원만, 60px), 기지에서 내릴 때 **순서가 맞는 글자만** 단어에 채워진다. 틀린 글자는 거부(-30)되고 그 인원은 지상으로 돌아간다. → 뜻만 보고 철자를 알아야 함. 인원 간격 130 이상 보장(옆 사람이 같이 타지 않게).
- **위협 빈도 완화(2026-11-15)**: 대공 시설 발사 간격 약 1.9배 증가(스테이지1 기준 SAM 9초/대공포 6.5초), 발사 **경고(붉은 링 0.65~0.8초)** 후 발사, 전체 발사 간 최소 간격(threatGap 1.8~3.5초), 동시 미사일/대공포탄 수 제한(1~2), 사정거리 900→650, 적기 편대는 편대 간 쉬는 시간(5.5~11초)·편대 내 간격 300px·화면 밖 "적기 접근 ▶" 경고. 최악(헬기를 사정권에 정지) 시뮬레이션: 미사일 8.5초·대공포 8.4초에 1발.
- **스테이지 난이도** `STAGES[0..4]`: SAM·대공포 수, 미사일 속도·선회율, 발사 간격, 예측 사격 정확도, 적기 속도·HP·사격 간격, 미끼 글자 수가 단계별로 상승. 보통은 1~3단계로 3스테이지, 쉬움은 한 단계 낮게(0~2), 어려움은 한 단계 높게(2~4) 시작. HUD에 ★1~5 표시.
- 검증: 스테이지/난이도별 시설 수(보통 1단계 = SAM1+AA2, 미사일 220), 공개 전 탑승 불가, 편대 4기(정답 1), 오답 격추 -50·소거, 정답 격추 공개·구출 가능.

### 스테이지 프레임워크 (사용자: "모든 게임이 스테이지가 매우 많을 것")
- 모든 게임을 `stage index → 난이도 파라미터 + 콘텐츠(단어 묶음)`로 데이터화한다(손으로 수백 개를 만들지 않고 곡선 함수 + 10단계마다 보스/이벤트).
- 콘텐츠는 기존 단어 학습의 **Day/Track 단어 묶음**에 연결하는 안이 자연스럽다(스테이지 N = 학생 트랙의 N번째 Day).
- 진행 저장: `game_stage_progress(student_id, game, stage, stars, best_score, cleared_at)` 같은 표. 해금 규칙(앞 스테이지 1★), 별 3개 기준(점수/정확도/시간).
- UI: 게임 카드 안에 스테이지 지도(잠금/해금/별), 이어하기.

### 실제 단어장 연결 (사용자: "우리 단어장 단어를 다 넣어 챕터별·수준별로")
마이그레이션 기준 현재 데이터 구조(라이브 DB 데이터량은 미확인):
- `words`: text, lemma, **pos**, **meanings_ko[]**, **meanings_en_simple[]**, **meaning_pos[]**(뜻별 품사), **pronunciation_ko**(한글 발음), difficulty(1~5), frequency_score, examples_*, derived_terms. 부속: `word_grade_bands`(학년대), `word_sources`(수능/모고/TOEFL 등 출처), `word_semantic_tags`(주제 클러스터).
- `vocab_sets`(track_id, **order_index**) + `vocab_set_items`: 과정(track) 안의 순서 있는 세트 = Day. 학생별 `student_vocab_plans`/`student_vocab_assignments`, 학습 기록 `vocab_learning_attempts`.
- 매핑 제안: **세계 = 과정(track) 또는 출처·학년대, 스테이지 = 세트(Day, order_index)**, 수준 = difficulty/grade band. 게임용 어댑터 `세트 → {word, ko, def, pos, 발음}` 1개를 만들면 모든 게임이 공통으로 쓴다.
- 암기 모드 재료: 품사·뜻·한글 발음은 이미 있음. 없는 것: IPA, **혼동어(비슷한 뜻/비슷한 발음)** → 같은 품사·같은 semantic tag·비슷한 철자·비슷한 한글 발음으로 후보를 뽑고 AI/선생님 검수.

### 암기 모드 (사용자 제안, 2026-11-15, 설계만)
1. **노출(5초)**: 단어 철자 + 뜻(품사 포함) + 발음(IPA/음성)을 동시에 보여 주고 5초 뒤 사라진다.
2. **철자 먼저**: 사라진 단어의 철자를 떠올려 답한다.
3. **뜻(한꺼번에)**: 품사 포함 뜻 보기를 한 화면에 모두 제시. 비슷한 뜻을 섞어 헷갈리게.
4. **발음(한꺼번에)**: 발음 보기를 한 화면에 모두 제시. 비슷한 발음을 섞어 헷갈리게.
- 필요 데이터: 품사, 발음(IPA), 비슷한 뜻/비슷한 발음의 혼동어(AI 생성 + 선생님 검수 권장), 음성(TTS).
- 미결정: 한 번에 몇 개 단어를 묶을지, 철자를 입력으로 받을지 보기로 받을지, 단독 모드인지 각 게임 앞단 단계인지.

### WORD MEMORY 단어 위치 기억 (2026-11-15, 1차 구현) `MemoryGame.tsx`
- 외우기(카드에 단어가 몇 초간 보임, READY로 일찍 시작하면 남은 초×5 보너스) → 카드가 뒤집힘 → 뜻/정의가 나오면 그 단어가 있던 **위치의 카드**를 누른다. 영영(정의→단어 위치) / 한영(한글 뜻→단어 위치) / 영한(단어→한글 뜻 카드 위치).
- 스테이지 카드 수 4·6·8·10·12·15·20장(외우는 시간 5~12초). 보통은 6장부터, 쉬움 4장부터(시간 ×1.3), 어려움 8장부터(×0.8). 한 판 6스테이지, 목숨 3.
- 점수: 정답 100 + 속도 보너스(6초 이내) + 콤보 10씩, 스테이지 클리어 +200, PEEK(라운드당 1번, 카드 전체 1.5초 공개) -50. 오답은 정답 카드를 알려 줌.
- 검증: 스테이지별 카드 수, 오답(-1목숨·정답 공개)/정답(+160) 처리, 스테이지 클리어 +200, 다음 스테이지, 게임 오버. 화면 렌더·실제 조작·외우는 시간 체감은 미확인.
- 기획 미확인: "외울 때 보이는 정보"(단어만 vs 뜻도), 짝 맞추기(단어↔뜻 카드 쌍) 변형 여부.

### 보드게임 + 상황 시뮬레이션 (사용자 제안, 2026-11-15, 설계 대화만)
- **보드게임**: 말판을 주사위로 이동, 칸 색 = 영역(리딩/리스닝/스피킹/라이팅) 도전. 4영역 배지를 모으고 결승점 도착 또는 라운드 점수. 도전은 TOEFL 2026 모듈 재사용. 쟁점: 스피킹/라이팅 판정(자동 판정 가능한 형태 먼저, 자유 답변은 게임 후 AI 리뷰). 미결정: 플레이어(혼자+AI 추천)·판정 방식.
- **상황 시뮬레이션**(안드로이드/애플 언어학습 앱용): 그 언어를 쓰는 나라들의 실제 상황(공항·호텔·식당·교통·쇼핑·병원 등)을 분기형 시나리오로. 한 장면에서 듣기(상대 말)·말하기(응답)·읽기(표지판·메뉴)·쓰기(양식·메시지)를 함께 연습. 나라별 팩(미국/영국/호주/캐나다…). 코리아 트립 GDD(보류 중)와 같은 계열 — 비주얼노벨형 웹 프로토타입(명동 한 구역)이 출발점.
- 보드게임의 "상황 칸"으로 시뮬레이션 장면을 끼워 넣는 연결 가능.

### 대형 로드맵 (사용자 제시, 2026-11-15)
1. **올림픽(모든 종목)** — 종목별 게임 묶음(클레이 사격, 100m, 계주, 크로스컨트리, 역도, 야구, 스노보드, 컬링, 당구). 명칭은 상표 문제로 자체 이름 권장.
2. **콕핏** — 구현됨(키보드 이동·Space 사격). 이후 확장 가능.
3. **Word Rescue** — 헬기 횡스크롤. 지상의 인원(철자 = 목표 단어/문장을 이루는 글자)을 착륙해서 태워 기지로 귀환. 지대공 미사일·대공포를 피함. 보기(선택지)를 미사일/총알로 격추 가능. (미사일에 보기를 붙이는 규칙은 확인 필요)
4. **저격 게임** — 상대 저격수 등 모든 공격을 피하며 타깃(암살 대상)을 저격. 스코프 시점, 숨 참기·흔들림, 적 저격수 섬광 경고 회피, 오답 인물 사격 시 경보.

### 다음 순서 (사용자 요청)
1. **Word 오목**: 5목. 칸을 골라 문제를 맞히면 돌을 놓는다(오답이면 턴 넘어감). AI 대전 / 같은 기기 2인(반 대항전). 판 크기 9x9~13x13.
2. **그림 보고 동의어 찾기**: 그림(단어를 나타내는 이미지)을 보고 동의어를 찾는 게임. 이미지 출처(AI 생성+선생님 검수 / 아이콘·SVG)와 방식(보기 고르기 / 기존 엔진에서 동의어만 격추)을 정해야 함.

### 추가 학습 모드 후보 (사용자 제안, 미착수)
지문 암기 · 작문 · 해석 · Conversation · 문법 · 빈칸 추론. 기존 틀에 매핑하면: 빈칸 추론 = 철자 조립/단어 낙하의 문장 버전, 문법 = 연결어·어법 고르기를 게이트/과녁으로, 해석 = 영한/한영 조립, 작문 = unscramble(어순)에서 시작, Conversation = 상황 문장 선택(레이스 게이트·콕핏 타깃).

### 차량형
- **짐카나**: 콘과 게이트가 있는 코스에서 정답 게이트로 통과, 오답·콘 접촉은 시간 패널티.
- **드리프트**: 코너마다 문제, 정답이면 드리프트 각도 유지.
- (레이싱 프로토타입이 이 둘의 기초가 된다.)

### 슈팅형
- **콕핏 (가제, 제목 확정)**: 조종석 시점의 슈팅 게임. 아직 규칙 미정 — 아래 질문 필요.
  - 시점: 조종석 안에서 정면을 보는 1인칭(적이 다가옴) vs 위에서 내려다보는 종스크롤.
  - 학습 연결: 뜻에 맞는 단어 적기만 격추 / 철자 조립(글자를 순서대로 격추) / 지문 문장 조각 격추 중 무엇?
  - 활쏘기 낙하 서바이벌과 규칙이 비슷하니 차별점(조종석 계기판·레이더·무기 선택)이 핵심.

### 지문 암기형 (철자 조립 엔진 확장)
| 방식 | 학습 내용 |
|---|---|
| 문장 순서 잡기 | 지문의 문단 흐름 — 떨어지는 문장을 지문 순서대로 쏜다 |
| Unscramble 문장 | 어순 — 단어/구 조각을 순서대로 쏴 문장 완성 |
| 연결어 고르기 | 논리 흐름 (However, Therefore …) |
| 빈칸 쏘기 | 핵심 단어 암기 |
| 한글→영어 조립 | 해석만 보고 문장 전체 암기 |
| 지시어 찾기 | it/they/this가 가리키는 대상 |

권장 학습 순서: 문장 순서 → unscramble → 연결어 → 빈칸 → 한글→영어(가릴수록 어려워짐).
먼저 만들 것 추천: **unscramble 문장 + 연결어 고르기**.

## 3. 공통 틀 구상
- 올림픽 허브 화면(종목 선택), 종목별 금/은/동 기준, 반 랭킹(선택).
- 문제 데이터는 기존 단어 DB, 지문은 "학생이 푼 Reading 지문" 또는 "선생님 등록 지문"(타자 암기 훈련 소스 재사용).
- 지문 문장 분리·연결어 위치는 AI 생성 → 선생님 검수(Hi-내신 변형문제 방식).

## 4. 아직 정하지 못한 것
1. 첫 완성 종목은? (클레이 사격 / 100m / 스노보드 / 레이싱 다듬기)
2. 학생끼리 **랭킹**을 겨루는가, 혼자 **기록**을 깨는가? 랭킹이면 저장 데이터와 DB 설계가 필요.
3. 레이싱의 "카운터"는 카운터 스티어(드리프트)로 가정했다 — 확인 필요.
4. 지문 소스: 푼 지문 / 선생님 등록 / 둘 다.
5. 조각 단위: 단어 vs 구(3~4단어). 구 기본 + 쉬운 지문은 단어 옵션을 추천.

## 5. 해결할 점 (현재 프로토타입)
- 낙하 모드의 위쪽 문제 패널이 떨어지는 단어를 가림.
- 매달린/날아가는 과녁: 과녁 크기 축소, 단어 수 증가 미적용.
- 데모 단어를 실제 단어 DB와 연결.
- 효과음/BGM 없음. 폰 성능 테스트 안 함. 일부 기능(아이템 효과, 결과 화면 등) 실제 플레이 확인 안 함.
