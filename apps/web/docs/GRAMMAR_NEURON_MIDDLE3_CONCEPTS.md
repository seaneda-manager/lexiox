## 확인이 필요한 판단

1. 묶음 크기: 한 개념 = 레슨 1개(설명·깜지·빈칸·Drill·문제 25)로 보고 묶었음. 너무 크면(예: 현재완료 3유닛, 복합관계사 3유닛, 문장성분 6유닛) 쪼갤 수 있음.
2. 5-10~5-12(목적격보어 to부정사/원형부정사)는 1장 5형식 개념과 겹쳐서, 지각·사역은 1장 개념에 흡수하고 5-10만 별도 개념으로 둠.
3. tier는 "이 책 기준 난이도"임. 레벨 1~5 설명·문항은 같은 개념 안에서 따로 만들며, 레벨 정의(예: L1=중1 수준 … L5=고등 내신)는 스키마 확정 때 정해야 함.
4. 14장(문장의 이해)은 개념 6개로 쪼개지 않고 종합 1개로 둠 — 다른 개념들을 문장 성분 관점에서 다시 묶는 단원이라서.
