## 2. 개편 목표
1. 학생: 단어 관련 모든 것을 **한 화면(허브)** 에서 보고 들어간다. 사이드바는 간략화.
2. 선생님/관리자: 학생(또는 반) 한 명 기준으로 **한 화면에서** 진도·복습·시험·모드를 조작한다.
3. 복습 규칙을 **하나의 정책 + 설정값**으로 통일하고 조절 가능하게 한다.
4. 모드를 줄이고(정의 후), 단계별 시간 배정을 가능하게 한다.
5. 숙제(집) / 시험(학원) 역할을 화면과 문구에서 명확히 한다.
6. 가려지거나 죽은 기능을 복구하거나 정리한다.

## 3. 학생 허브 위젯 화면

### 3-1. 구성 (위젯 카드)
| 위젯 | 내용 | 진입 |
|---|---|---|
| **오늘 할 일** (최상단) | 지금 해야 할 한 가지: 학습 중 Day / 복습 N개 / 시험 잠김·가능 | 한 번에 이어하기 |
| **오늘의 학습** | Day, 단계 진행 점(PreScreen→스펠링→학습→Speed→깜지), 소요 예상 시간 | 학습 시작/이어하기 |
| **복습** | 오늘 복습할 단어 수, 의무 여부, 이번 회차 | 복습 시작 |
| **시험** | 상태(잠김/가능/완료+점수), 선생님 시험 새 배정 | 시험 이동 |
| **약점** | 자주 틀리는 단어(뜻/스펠링 구분) | 약점 연습 |
| **게임** | 단어 게임 진입 | 게임 |
| **통계·알림** | 누적 단어, 품사 분포, 선생님 노티스 | 상세 |

- 각 위젯은 요약 1~2줄 + 배지/알림 + 한 개의 주 버튼. 설명문은 최소화.
- hub-new의 샘플 문장·작문 테스트 fallback은 제거 또는 실데이터 없을 때 위젯 숨김.
- 죽은 링크 2개는 위젯 개편 시 제거하거나 실제 페이지로 연결.

### 3-2. 사이드바 간략화
- LEXiOX: `어휘` 구역을 **"단어" 1개**(허브)로. 시험·복습은 허브 위젯에서 진입. 배지(복습 N)는 사이드바 항목에 유지.
- "선생님 시험"은 시험 위젯 안으로. "단어 게임"은 게임 위젯으로 유지하되 사이드바 중복 제거.
- TOEFL 프로그램은 기존 "시험·복습" 구역 구조와 정합성을 맞춰야 함 [별도 확인].

## 4-1. 학습 방식 · 요소 조절 (11-25 사용자 논의로 확정된 방향)
- 옵션 1~4 폐지(트랙 배포 UI에서 제거 완료, DB 컬럼은 유지). 운영 분포: 옵션1=7, 옵션3=8, 옵션4=1, 옵션2=0.
- **배정 방식 2가지**: (A) 전체 학습(PreScreen→스펠링→학습→Speed→깜지) / (B) 시험만.
- **요소 개별 on/off**: 단계(PreScreen, 스펠링, 학습, Speed, 깜지, 복습 등)를 따로 켜고 끔. "시험만"은 학습 요소 전부 끈 경우와 같으므로 하나의 설정으로 통합 가능.
- **적용 단위(확정): 학생별, 클래스별.** (트랙별은 일단 제외.) 우선순위는 학생 > 클래스 > 기본값.
- **시험만(B) 규칙(제안)**
  - 시험 자격 조건(학습 완료) 면제. 완료 이벤트는 "시험 제출"로 대체. [확인 필요: Day 진행(cursor), 복습 항목 등록(Day 완료 시 호출), 시험 자격 판정, 선생님 복습 현황 집계가 "학습 완료"에 의존하는 지점]
  - 집 숙제는 선택: 최근 3일 누적 오답 단어 깜지(틀린 것만, 의무 아님·알림 방식).
  - 복습 항목 소스 = 시험 오답(뜻 틀림 / 스펠링만 틀림 구분 저장, 선생님이 포함 유형 선택).
  - 누적 관리: 하루 복습량 상한(기본 예시 20, 설정값) + 초과분은 다음 날로 이월 큐. 우선순위: 반복 오답 > 최근 오답 > 오래된 오답. 연속 2회 정답이면 졸업, 3회차 오답은 lapsed(기존 정책).
  - 약한 학생에게 시험만을 줄 때: 시험 분량 축소, 시험 점수 기준(예: 70%, 설정값) 미만이면 Day를 넘기지 않고 오답 재시험, 학생별 하루 복습량 낮춤, 큐가 임계치 넘으면 선생님 알림.
  - 위 숫자는 모두 제안값(근거 자료 없음).
- 구현은 스키마 변경 포함 → 사용자 승인 후 진행.

## 4-2. "학습 완료" 의존 지점 조사 결과 (11-25, 코드 읽기)
**완료의 단일 신호** = `student_vocab_assignments.completed_at`.

- 정리 후보: ②·③의 중복 완료 경로(어느 쪽이 실제 호출되는지 확인 후 통합).

## 6. 관리자/선생님 통합 컨트롤
### 6-1. 학생 컨트롤 패널 (progress 화면 확장)
학생 한 명 선택 시 한 화면에서:
1. 진도 타임라인(Day별 단계 상태·정확도·틀린 단어)
2. **조작**: 다음 회차로 넘기기(skip), 되돌리기, 복습 skip(사유 기록), 복습 설정, speed 모드, 단계별 시간
3. 시험: 시험 배정/설정 바로 가기(해당 학생 컨텍스트 유지)
4. 변경 이력(누가/언제/무엇을) — 학생 영향이 큰 조작이므로 기록 필요

### 6-2. 설정 계층 (전체 → 반 → 학생)
- 시험 설정이 이미 3계층 구조. 같은 방식으로 **복습 설정**(개수, 대상 유형, 회차 수)과 **단계별 시간**을 추가.
- 화면은 한 곳(설정 허브)에서 계층 전환. 현재 3곳에 흩어진 시험 설정은 통합 후보.

### 6-3. 단계별 시간 배정
- 현재: speed 타이머(2~30초)만. 제안: 단계(PreScreen, 스펠링, 학습, Speed, 깜지)별 **권장/제한 시간**을 설정값으로 도입. 제한은 강제가 아니라 안내+기록 우선(학생 불만 방지) → 효과 보고 강제 여부 결정.

## 7. 숙제/시험 역할 정리
- 정의(사용자 확인): 집=학습(숙제), 학원=시험. 문제: 학습 미완료로 시험이 잠기는 경우가 많고 학습 완료가 잘 안 됨.
- 제안:
  - 허브 최상단에 "오늘 숙제" 완료율과 시험 자격 상태를 항상 노출.
  - 선생님 화면에 **미완료 학생 목록**(어느 단계에서 멈췄는지)을 즉시 표시 → 학원에서 바로 독려.
  - 완료 조건(깜지까지)은 현행 유지. 완료 못 한 학생을 위한 선생님 예외 처리(skip 등)는 이력 기록과 함께.

## 8. 숨겨진/죽은 기능 정리
| 항목 | 상태 | 조치 제안 |
|---|---|---|
| 이어동사 | Tetris 게임에만 데이터 | DB 단어집 존재 확인 → 있으면 허브 위젯·배정에 노출, 없으면 단어집 신규 제작 계획 |
| 숙어 | 품사 라벨뿐 | 위와 동일 |
| /vocab/speed-challenge, /vocab/asteroid-game 링크 | 페이지 없음 | 제거 또는 복구 |
| LEARNING_STAGE1/2 분기 | 사용 여부 불명 | 로그/데이터로 확인 후 제거 |
| 복습 규칙 이중 | 두 곳에서 동작 | §5 통합 |
| `/vocab/*` 중복 페이지(hub vs hub-new, exam vs test, drill 등) | 일부 구버전 가능 | 접근 로그 확인 후 정리(별도) |
| 추가 조사 필요 | "전에 만들었지만 가려진 큰 부분" | 사용자가 기억하는 기능명을 알려 주면 코드·DB에서 추적 |

## 9. 단계별 실행 계획 (제안)
1. **정리/복구 (낮은 위험)**: 죽은 링크 제거, 샘플 데이터 fallback 정리, 이어동사·숙어 DB 확인, 사용되지 않는 stage 조사.
2. **허브 위젯화**: hub-new를 위젯 구성으로 교체, 사이드바 간소화. 세션 본체는 그대로.
3. **복습 설정화**: 정책 확정 → 설정 테이블 → 두 경로 통합 → 관리자 설정 UI. (스키마 변경 포함 → 리스크 작업은 사용자 승인 시점에)
4. **관리자 통합 패널**: progress 확장, skip·복습 skip·이력, 설정 계층 UI, 단계별 시간.
5. **모드 간소화·시험 설정 통합**: 용어 통일, 화면 3곳 통합.
- 스키마 변경·대량 마이그레이션은 계획만 제시하고 승인 후 진행(이전 합의 사항).

## 10. 결정이 필요한 것
1. "4개 mode"가 정확히 무엇인가.
2. 복습 대상에 "스펠링만 틀린 것"을 별도 유형으로 둘지, 선생님이 유형을 고르게 할지.
3. 복습 skip을 허용할 때 사유 기록과 학생 노출 여부.
4. 단계별 시간: 안내만 / 강제 여부.
5. 사이드바에서 시험·복습을 허브로 흡수해도 되는지(TOEFL 프로그램 구조와의 일관성).
6. 가려진 기능 중 사용자가 기억하는 것의 이름(이어동사·숙어 외).
7. 1단계(정리/복구)를 바로 시작해도 되는지.
