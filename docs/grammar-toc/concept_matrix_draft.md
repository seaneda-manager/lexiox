## D. 관찰
- **기초→심화 사슬이 그대로 보인다.** 같은 개념(to부정사, 문장의 형식, 접속사, 비교, 조동사)이 교재 1에서 기초, 교재 2에서 심화로 나뉜다 → 한 개념에 **레벨별 포인트 목록**을 두는 구조(유니버설 챕터 + 변형)와 정확히 맞는다.
- **중2 2학기 5·6과 내용과 직접 연결된다.** used to(2.7), so ~ that(4.10, 10.7), 지각동사(9.8), 목적격 관계대명사(12.3)는 모두 교재 2에 있다 → 직전 보강 자료를 이 개념 구조에 연결할 수 있다.
- **아직 없는 것**: 수일치(`unit01` taxonomy), 어법 심화(TEPS/수능형), 서술형 문장 전환 같은 "목적" 축은 목차에 드러나지 않는다 → 변형(목적) 쪽에서 채운다.
- 교재 1 매핑 초안(`book01_concepts_draft.md`)의 개념 번호는 교재 2 반영 후 하나의 번호 체계로 재정렬한다.

### E.3 관찰
- 교재 1 → 2 → 3이 **같은 개념의 3단계 심화 사슬**이다. 한 개념에 기초/중간/심화 포인트를 붙이는 구조가 그대로 맞는다.
- 기출 위주 교재라서 단원 끝에 **"내신 기출"**, 챕터 끝에 **"중간고사·기말고사 실전문제"**(객관식 25 + 주관식 25)가 있다 → 우리 6단계 흐름의 5(연습)·6(실전)과 대응. 실전 문제의 주관식 유형(어법 오류 고치기, 문장 완성, 영작)은 변형(목적) 설계 때 참고한다.
- **교재 3은 TEPS·수능형이 아니라 중3 내신형 어법**이다. 고등 어법/TEPS는 별도 교재 목차가 필요.
