## 1. 한눈에 보기

학생은 **Day 단위**로 학습한다. 하루에 기본 1 Day, 최대 2 Day.
한 Day = `사전확인 → 스펠링 → 요약 → 학습 → 스피드 → 깜지 → Day 완료`.
Day를 끝내면 **학원 단어 시험** 응시 자격이 열린다. 점수·활동은 **포인트/레벨/스트릭**으로 적립되고, 포인트로 **Perk**를 교환한다.

## 3. 소요 시간

코드에 "목표 시간" 값은 **스피드 제한시간 하나뿐**이다. 나머지는 측정 전 **제안**이며 확정이 필요하다.

| 구간 | 값 | 상태 |
|---|---|---|
| 스피드 문항당 제한시간 | 트랙별 2~30초 (기본 15초, 세션 폴백 6초) | ~~구현~~ ✅ |
| Day 1회 전체 소요 | ☐ 제안: 20~30분 (단어 수에 따라) | ☐ 실측 후 확정 (학습시간 `total_study_time` 기록 필드는 있음) |
| 단어 수 상한 | 50단어/세션 (`MAX_WORDS`) | ~~구현~~ ✅ |
| 하루 총 학습 | 1 Day 기본, 최대 2 Day | ~~구현~~ ✅ |
| 학원 단어 시험 소요 | 응시 시간(`duration_seconds`) 기록만 있고 제한시간 없음 | ☐ 시험 제한시간 결정 필요 |

## 4. Pass 조건

### 4-1. 단계별

| 단계 | 현재 코드 | 상태 |
|---|---|---|
| 사전확인 | 통과 기준 없음 (완료만 하면 진행) | ~~구현~~ ✅ |
| 스펠링 | 틀린 단어는 학습 단어로 편입 (탈락 없음) | ~~구현~~ ✅ |
| 스피드 | **정확도 ≥ 70% = passed** 로 기록. 정식 모드에서만 게이트(미달 시 오답 재도전 1회). 간략 모드는 게이트 없음 | ~~구현~~ ✅ |
| 정식 모드 2차 미달 | 재도전 후에도 미달이면 **그대로 깜지 → Day 완료** (Day 재수강 없음) | ~~구현~~ ✅ (☐ 정책 확인 필요) |
| Day 완료 조건 | 깜지까지 마치는 것. 점수 하한 없음 | ~~구현~~ ✅ |

### 4-2. 학원 단어 시험 (Day 완료 후)

| 항목 | 현재 코드 | 상태 |
|---|---|---|
| 응시 자격 | 해당 Day 완료 필수 (전역 설정 `skip_learning_check`로 면제 가능) | ~~구현~~ ✅ |
| 출제 범위 | Day 단어의 `coverage_ratio`% (기본 70%, 30~100), 순서 random/grouped, 범위 global/class/student별 설정 | ~~구현~~ ✅ |
| 틀린 것만 다시 보기 | `use_wrong_only` | ~~구현~~ ✅ |
| 채점 | 문항 3점 만점, 힌트 1단계 −1점 / 2단계 −2점(최소 1점), 연속 정답 보너스(최대 5연속 × 10%) · 점수 0~100 기록 | ~~구현~~ ✅ |
| **통과(합격) 기준** | **코드에 없음** — 점수만 저장 | ☐ 결정 필요 |

### 4-3. 통과 등급 (제안 — 확정 필요)

스피드의 기존 기준(70%)에 맞춰 3단계로 제안한다.

| 등급 | 시험 점수 | 결과 |
|---|---|---|
| **완전 통과** | 90점 이상 | 다음 Day 정상 진행, 보너스 포인트 |
| **조건부 통과** | 70 ~ 89점 | 다음 Day 진행 가능, 틀린 단어는 **오답 깜지**(자동) 후 누적 오답 퀴즈에 편입 |
| **불합격 → 나머지 공부** | 70점 미만 | 아래 5번 나머지 공부 부여, 같은 Day 재시험 |

☐ 제안값(90/70)은 원장님 확정 전까지 코드에 반영하지 않음.

## 8. Punishment (제재)

> 원칙(제안): **포인트를 깎지 않는다.** 이미 번 포인트를 빼면 동기가 꺾이므로, 제재는 알림 → 경고 → 면담 순으로 한다.

| 항목 | 내용 | 상태 |
|---|---|---|
| 연체 알림 | 완료 안 된 과제의 `available_at`이 지나면 학생에게 `overdue` 알림 생성 (크론) | ~~구현~~ ✅ |
| Yellow Card 테이블 | 선생님이 학생에게 발급, 상태 active/resolved/dismissed, 심각도 yellow/red | ~~구현~~ ✅ |
| Yellow Card 발급 화면 | 학생 리포트에서 사유 입력 후 발급 | 🔶 화면은 있으나 `getUser()` 결과를 `data.user`로 꺼내지 않아 **실제 저장이 안 될 가능성** 있음 — 수정·검증 필요 |
| Red Card 발급 | 테이블은 지원하나 발급 화면 없음 | ☐ |
| ☐ 자동 경고 | 제안: 연체 알림 3회 누적 → 선생님에게 "Yellow Card 제안" 표시 (발급은 선생님이 확정) | ☐ 제안 |
| ☐ 카드 효력 | 제안: Yellow 2장 → Red / Red → 학부모 면담, 해당 월 Perk 신청 보류 | ☐ 제안 |
| ☐ 나머지 공부 불참 | 제안: 불참 1회 = 재스케줄, 2회 = Yellow Card 제안 | ☐ 제안 |
| ☐ 카드 해소 | 제안: 4주간 신규 제재 없으면 `resolved` | ☐ 제안 |
